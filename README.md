# 基于开源鸿蒙的智慧全息宠物关怀系统

> 参加嵌入式芯片与系统设计竞赛作品

## 项目简介

本作品面向虚拟宠物陪伴与居家环境感知场景，基于 OpenHarmony/SwanLinkOS 构建智慧全息宠物关怀应用。当前副本仅包含鸿蒙应用源码、配置和运行资源。

## 系统架构

```
┌──────────────┐    HTTP/WebSocket    ┌──────────────┐
│ 鸿蒙应用端    │ <──────────────────> │ 可选服务端    │
│ ArkTS/ArkUI  │                     │ 环境与 AI 服务 │
└──────────────┘                     └──────────────┘
```

## 目录结构

```
.
├── AppScope/                       # 应用级配置
├── entry/                          # 鸿蒙应用主模块
│   └── src/main/ets/
│       ├── pages/                  # 18 个页面（领养/聊天/喂食/档案...）
│       ├── common/
│       │   ├── components/         # UI 组件（PetSprite/PetStatusBar...）
│       │   ├── services/           # 12 个业务服务（AI/传感器/语音/推流...）
│       │   ├── models/             # 数据模型
│       │   └── constants/          # 常量定义
│       ├── entryability/           # Stage 模型 Ability
│       └── resources/              # 资源配置（颜色/字符串/路由）
├── build-profile.json5             # 工程构建配置
├── oh-package.json5                # 依赖管理
└── hvigorfile.ts                   # 构建脚本
```

## 核心功能

### 软件交互
- 宠物领养、日常照料、玩耍互动
- AI 多模态对话（文字/语音）
- 成长档案、梦境日记
- 环境数据可视化

### AI 智能
- 人格化对话、三层记忆机制
- 自主情绪变化、专属梦境生成

### 全息显示
- 四视角同步渲染
- 亚克力光学金字塔浮空 3D 影像

## 主要性能指标

| 指标 | 实测结果 |
|------|---------|
| 全息动画渲染帧率 | 稳定 28fps |
| 多端同步延迟 | 平均 36ms |
| 应用冷启动时长 | 2.1s |
| 本地数据库占用 | 72MB |
| 传感器数据上报间隔 | 1s |
| 离线功能 | 基础陪伴类核心功能可用 |

## 技术栈

- **前端应用**：OpenHarmony / ArkTS / ArkUI / Stage 模型
- **后端服务**：FastAPI / WebSocket / 本地大模型 / 向量记忆数据库
- **本地存储**：OpenHarmony RDB 关系型数据库
- **通信协议**：HTTP / WebSocket / JSON 标准报文

## 开源说明

本仓库仅开源部分关键代码：

- 构建配置文件

不包含：图片/音视频等大体积资源、完整 SDK、本地 AI 模型、文档素材。
